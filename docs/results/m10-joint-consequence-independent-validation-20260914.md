理想条件下，模型相对公开联合基线在 360 个双方均有效的配对分支上 on-time 差为 0；16 个父 episode 的父级均值差为 `0`，bootstrap 95% 区间为 `[0, 0]`。因此没有理想通信下的独立决策增益证据。模型比公开基线多 8 个删失分支，不能用略高的未删失均值宣称改善。

弱通信下，模型相对公开联合基线的双方均有效子集为 167 个配对分支、14 个父 episode：分支级 on-time 差均值 `+0.1856`，父级均值差 `+0.1301`，父级 bootstrap 95% 区间 `[0, 0.2832]`，33 胜 / 132 平 / 2 负。相对当前规则为 189 个双方均有效分支、14 个父 episode，父级均值差 `+0.1301`，区间同为 `[0, 0.2832]`，33 胜 / 154 平 / 2 负；相对零差值为 159 个双方均有效分支、13 个父 episode，父级均值差 `+0.1401`，区间 `[0, 0.3077]`，33 胜 / 124 平 / 2 负。

这些弱通信点估计受到方法相关删失影响：模型有效 210/360，而公开联合只有 168/360；因此不能把四个方法的有效分支均值直接当作无偏总体比较。父级样本只有 13–14 个，区间包含无效应边界，按预注册规则结论为证据不足，不扩样、不因接近改善而启动融合。

## 选择、成本与安全

- 理想条件中当前规则与公开联合选择完全一致；模型相对公开联合在 52 个可用前缀中有 26 个首步选择不同，但直接后果没有差异。
- 弱通信中模型相对公开联合有 24/45 个可用前缀首步选择不同；其余选择差异与结果差异不能只用命中率解释。
- 弱通信双方均有效配对中，模型相对公开联合平均增加约 `4.63` 条通信记录、`829.9` 字节序列化代理量，分支计时增加约 `0.1603 ms`；这些是仿真代理/本机记录口径，不是真实网络流量。相对当前规则为约 `4.32` 条、`782.8` 字节和 `0.0878 ms`。
- 弱通信双方均有效配对中，模型相对公开联合的物理到达记录差约 `+0.1856`/分支，主机确认记录差约 `+0.2395`/分支，按时主机确认差约 `+0.1078`/分支；它们是通信敏感性指标，不能替代研发主指标，也受删失和路径差异影响。
- 所有 3104 条分支的安全违规计数为 0；完整性审计无重复方法键、无固定任务集不一致、无配对外生 key 不一致、无选定动作与预先选择记录不一致。该“0”仅表示本次 replay 已记录审计范围内未观察到违规，不是生产安全保证。

## 选择结论

本轮选择：**证据不足，停止当前联合后果模型的融合路线**。不采用“独立决策价值有支持”结论，也不将其写成模型无效的普遍定理。弱通信的点估计改善值得作为假设保留，但在方法相关删失和有限父级样本下不足以支持有界 GPPO 融合 pilot；理想条件没有增益，公开联合基线仍是强对照。

本轮回答：

1. 数据存在部分可重复的弱通信候选差异，但当前验证不能把差异稳定归因给模型而非删失/路径差异。
2. 公开联合基线在理想条件与当前规则完全一致，在弱通信多数前缀也保持相同或近似的选择；模型相对它的额外价值没有达到预注册可支持程度。
3. 模型出现弱通信点估计排序/选中后果改善，但父级不确定性与有效分母限制使其只能算有限探索证据，不能算独立决策价值成立。
4. 按停止规则不继续当前融合路线；通知/调度工程扩展不重开。若未来回到该假设，必须先预注册不依赖方法路径的删失处理与更强的父级验证设计，而不是直接训练或扩样。
