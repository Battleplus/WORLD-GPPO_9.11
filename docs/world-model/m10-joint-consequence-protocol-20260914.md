# M-10 联合任务集合后果协议 v0.1.0

状态：设计冻结与接口实现；本提交不生成数据、不启动训练。

## 1. 可证伪假设

只预测被选任务自己的到达时间，可能漏掉 UAV 被占用后对同一时刻其他公开待办任务造成的机会成本。若对同一决策前缀的固定任务集合预测联合后果，能够在相同状态候选排序中超过合法公开信息基线，并在独立父 tape 上改善选中分支的按时物理到达，则该假设得到支持；否则停止该方向。

这不是全局最优 Q 值，也不是对任意后续策略的承诺。标签对应固定的续行控制器。

## 2. 冻结合同

- 父协议：`world-gppo-9.11-arrival/0.1.0`；任务为到达目标区域即物理完成。
- `physical_arrival` 是研发主指标；`host_confirmation` 只作独立通信敏感性指标，不混入联合标签。
- 每个合法候选从同一个公开决策前缀出发，第一步执行该候选。
- 后续每一步使用 `traditional_public_controller_v1`（当前合法公开规则），每个分支的动作和观察摘要都写入账本。
- 同一父 tape、前缀和 `repeat_id` 的候选共享场景和 `exogenous_key`；分支 trace digest 只作为审计证据，字符串相同本身不被当成随机流证明。
- 保持动作合法性、通信、ACK、lease、fencing、能量和故障门禁；不启用 bounded retry、不改变奖励、不启用事件触发。
- 模型输入当前只使用前缀末端的 Graph-5 公共快照和候选身份；不附加隐藏状态。若后续加入 history，必须是同一前缀已经合法公开的观测序列，维度和初始化另行版本化并在所有候选间保持一致。

## 3. 标签定义

前缀时由公开 `TaskPolicyView` 确定固定的、尚未结束的任务集合 `J`。同一前缀的所有候选和重复分支使用完全相同的 `J`，未来释放的任务和完整 episode 结果不进入该标签。

对每个 `j ∈ J` 保存：

- 物理到达时间；
- 是否在 physical deadline 前到达；
- 截止结局是否已被观察；
- 未到达、迟到或观察窗口删失的分类。

候选聚合目标为：

- `new_on_time_count_for_fixed_public_task_set`：窗口内 `J` 中按时物理到达的任务数；
- `deadline_failure_count_for_fixed_public_task_set`：已观察截止结局且未按时到达的任务数；
- 相对预先指定的合法规则参考动作的配对差：候选减参考。

只要固定集合中有一个任务的截止结局尚未观察，聚合计数和配对差的 mask 为 false；不能把删失当成失败。单分支幸运结果不能直接解释为成功概率或最优动作。

完整字段约束见 [`schemas/m10-joint-consequence-v1.schema.json`](../../schemas/m10-joint-consequence-v1.schema.json)。旧的单候选到达时间/失败标签仍由旧 schema 解释，不在本协议下改名复用。

## 4. 非学习基线和验收顺序

离线先比较：

1. 当前合法规则（冻结参考动作）；
2. 仅用公开位置、deadline、能量、服务和待办集合构造的联合机会成本评分；
3. 未来冻结后的联合后果预测模型。

联合评分必须显式估计选择一个 UAV 后其他公开待办任务的可达性/资源机会成本，不读取隐藏真值。若该评分已解释候选差异，模型必须以它为强基线，而不是只和常数或随机排序比较。

离线排序、选中分支的固定续行结果和在线 GPPO 增益分开验收。即使离线排序改善，也不能直接外推到 GPPO 的续行分布。

## 5. 数据隔离与预算登记

开发 pilot（本提交只登记、不执行）：train 8 个父 episode、validation 4 个父 episode；每个父 episode 4 个公开前缀，每个前缀最多 25 个合法候选，每个候选 3 次外生重复。test/OOD 在该 pilot 中为 0，不能称盲测。

只有 pilot 通过后才允许另行冻结 formal 数据：64/32/64/32 个父 episode（train/validation/test/OOD），全部前缀、候选和重复分配按父 episode 留在一个 split；不按旧策略失败结果筛选，不删除真实失败。

数据生成预算与训练预算分开登记。预先声明的模型 pilot 为单 seed `1101`、最多 512 次 optimizer update、最多 4 epochs、validation patience 2、墙钟 20 分钟。其目的只是可行性和排序诊断，不是正式策略实验；不自动扩大预算。

## 6. 值得训练与停止条件

只有同时满足以下条件才值得启动后果模型训练：固定集合标签有足够非删失样本；同状态候选之间存在可重复的后果差异；共享外生随机条件有分支证据；split 无父轨迹泄漏；联合公开基线未解释全部差异。

出现全量或近全量删失、候选差异由重复随机波动主导、公开联合评分已达到相同排序、模型没有额外排序价值、存在信息泄漏/安全违规/非有限状态，或预算耗尽时停止该假设。成功条件不是“训练完成”，而是独立父 tape 上的候选排序和选中联合后果均有可重复改善，且不牺牲 physical arrival 或突破固定成本/安全门禁。

通知机制和调度机制不在本阶段改变；bounded retry 的历史收益仍是工程候选，不得写成世界模型贡献。
